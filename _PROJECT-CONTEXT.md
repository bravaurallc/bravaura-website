# Bravaura Website — project context

**Paste this whole file into a new chat to bring Claude up to speed instantly.**

## What this is
A multi-page marketing website for **Bravaura LLC** — mobile art events across New Jersey (birthday parties, paint & sip, corporate team building, face painting, master classes). Hand-coded, fast, static HTML/CSS/JS. Not a website builder — Kendal asks Claude to make edits.

## Where it lives
Folder: `Work-Business/Website/` (inside the CoworkOS folder).
**To view it: open `index.html` in a browser (double-click it).** All pages link to each other.

## Pages
index (home), services, birthday-parties, paint-sip, corporate, face-painting, master-classes, quote (interactive estimator), about, contact, faq. Plus `pricing.html` which just redirects to quote.
Shared files: `css/styles.css`, `js/main.js`. Logo: `assets/bravaura-logo-final.png`.

## How it's built
Generated by a Python script: `Website/_build/build_site.py`. To change the site, edit that script and run `python3 build_site.py` (its OUT path already points at the Website folder), which regenerates every page consistently. Small one-off tweaks can be made directly in the HTML.
